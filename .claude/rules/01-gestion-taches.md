# Gestion des tâches

1. **Plan d'abord** : écrire le plan dans `artifacts/plans/XXX.md` avec des items cochables
2. **Valider le plan** : aligner avec l'utilisateur avant d'implémenter
3. **Suivre la progression** : cocher les items au fur et à mesure
4. **Expliquer les changements** : résumé haut niveau à chaque étape
5. **Documenter les résultats** : ajouter une section de review dans le plan
6. **Capturer les leçons** : mettre à jour `artifacts/lessons.md` après chaque correction
